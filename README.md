# AKOP - Akıllı İhbar ve Saha Operasyon Yönetim Platformu

Ankara Üniversitesi Bilgisayar Mühendisliği Bitirme Projesi

## Teknolojiler
- Backend: ASP.NET Core (.NET 10) - Microservices
- Mobile: Flutter
- Web: React + TypeScript
- Database: PostgreSQL

## Backend Mikroservisleri
- IdentityService
- InstitutionService
- ReportService
- RoutingService
- WorkOrderService
